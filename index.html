01

What is Query Cost?

Query cost represents the amount of computational work associated with executing a database query. Database optimizers consider different execution strategies before choosing a plan.

QueryLens uses an educational cost model based on query characteristics such as scans, index usage, joins, filtering, aggregation and sorting.

Table Scan Reads rows from a table to find matching records.
Index Search Uses an index to locate relevant rows more efficiently.
Join Combines records from two or more tables.
Temporary Structure May be needed for sorting, grouping or distinct operations.

FAQ

Frequently Asked Questions

Is QueryLens completely browser-based?

Yes. This GitHub Pages version performs its processing using JavaScript running in the user's browser.

Does QueryLens use a real database server?

No. The GitHub Pages version uses a generated demonstration dataset stored in browser memory. It does not require Node.js, SQLite or a server.

What SQL can I use?

QueryLens supports a useful subset of SELECT queries including filtering, sorting, aggregation, grouping and common joins.

Is the cost score a database optimizer's actual cost?

No. It is an educational cost metric derived from the detected characteristics of the submitted query.

Where is analysis history stored?

Recent analyses are stored in the browser's localStorage.

Can I save my analysis as a PDF?

Yes. Select Print / Save PDF from the Download menu and choose "Save as PDF" in your browser's print dialog.
