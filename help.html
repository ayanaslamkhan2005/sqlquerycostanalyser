How to Use QueryLens

Follow these steps to analyze SQL queries, upload SQL files, interpret cost estimation, and practice competitive exam questions.

⚡ Open Query Analyser 50 GATE DBMS PYQs → Browse FAQs ↓
01

Enter or Upload SQL

Type a SELECT query into the editor, pick from our ready-made Demo Queries dropdown, or click 📂 Upload .sql to upload your own SQL file directly.

02

Analyze Query & Cost

Click Analyze Query, or press Ctrl and Enter together. QueryLens parses the SQL and runs it against its in-browser dataset, instantly calculating computational cost.

03

Check the Score

The score runs from 1 to 100, where higher is cheaper. Read it alongside the estimated cost, execution time and rows returned.

04

Read the Cardinality

Selectivity is the fraction of rows your filter keeps. Estimated Rows is how many survive. Index Used names the index column, or reads "none" when a full scan is required.

05

Study the Execution Plan

Each line shows one operator with its estimated rows, its cost and its share of the total. The cost chart ranks the same operators so you can see where the work concentrates.

06

Apply the Advice

The Optimization Advisor explains what it found. Suggested Rewrites gives copy-ready SQL and CREATE INDEX statements to run against your own database.

07

Verify with Tests

Click Run Tests to execute built-in cases covering filters, joins, aggregates, operator precedence and invalid input. Each case asserts a specific expected outcome.

08

Download a Report

Use the Download menu for Text, Document, JSON or printable PDF. The report records your input, the plan, the cost breakdown, the recommendations and sample output rows.

09

Take the Quiz

Navigate to Quiz, choose how many questions you want and pick Easy, Medium or Hard. Answer one question at a time; each is marked immediately with an explanation.

10

Practise 50 GATE PYQs

Open Competitive Exam, search or filter by sections A–G, then select an option on any question. The correct answer and a step-by-step solution appear once you have chosen.

11

Switch Day or Night

Use the sun and moon button at the top right. Your choice is remembered in this browser for next time.

12

Reuse Past Queries

Analysis History lists your ten most recent queries. Click any entry to load and re-run it.

FAQ

Frequently Asked Questions

How do I upload a SQL file to estimate cost?

Click the 📂 Upload .sql button in the SQL Input panel or drag and drop your .sql or .txt file directly onto the editor. QueryLens will read the file and automatically compute the execution plan and cost score.

Is QueryLens completely browser-based?

Yes. All parsing, execution and costing run in JavaScript inside your browser. Nothing is sent to a server.

Does QueryLens use a real database server?

No. It generates a demonstration dataset in browser memory each time the page loads, using fixed seeds so results stay reproducible.

What SQL statements are supported?

SELECT queries with WHERE, AND, OR, NOT, parentheses, IN, comparison operators, INNER JOIN, LEFT JOIN, GROUP BY, HAVING, COUNT, SUM, AVG, MIN, MAX, ORDER BY and LIMIT.

What does the Query Score mean?

Scores run from 1 to 100, where 100 is best. They reward index usage, low selectivity and small result sets, and penalise full scans on large tables, unindexed joins and large sorts.

How is Selectivity calculated?

Selectivity is the fraction of rows expected to satisfy a WHERE condition. For an equality test on an indexed column with V distinct values, selectivity is 1/V. QueryLens multiplies selectivity by table cardinality to predict surviving rows.

Why does QueryLens recommend CREATE INDEX statements?

When a query filters or joins on an unindexed column, QueryLens detects the full scan and suggests an index that would turn that scan into a direct lookup.

Can I print or save a PDF of my analysis?

Yes. Choose Print / Save PDF from the Download menu, then select "Save as PDF" in your browser's print dialog. The print style sheet formats your analysis neatly on the page.
