What is Query Cost?

Query cost represents the amount of computational work associated with executing a database query. Database optimizers consider different execution strategies before choosing a plan.

QueryLens uses an educational cost model. It estimates how many rows survive each filter using table statistics, then charges every plan operator for the page reads and CPU work it performs.

Table Scan Reads every row of a table to find matching records.
Index Search Uses an index to seek directly to the matching range.
Selectivity The fraction of rows a predicate is expected to keep.
Join Combines records from two or more tables.
Temporary Structure Needed for sorting, grouping or distinct operations.
Cardinality The estimated number of rows flowing out of an operator.
