Technical Architecture

Key highlights of the QueryLens software design

1. Cardinality-Aware Cost Model

Modeled on PostgreSQL and SQLite query planners. Estimates column distinct value frequencies, evaluates predicate selectivity, and computes simulated page I/O and CPU operator costs.

2. Zero-Server Browser Execution

All AST parsing, SQL condition evaluation, query planning, plan tree generation, and live execution runs completely client-side in vanilla JavaScript with maximum privacy.

3. 50 Authentic GATE DBMS PYQs

Curated past-year question bank spanning Sections A through G (ER Models, Normalization, SQL, Relational Algebra, Concurrency Control, Indexing, and WAL Recovery) with step-by-step solutions.

4. Multi-Page Modular Experience

Separated clean pages for Analysis, Learning, Competitive Exams, Quiz practice, Documentation, and Credits, with drag-and-drop file upload, live reports, and theme persistence.
